魔獸VTX

版本 v1.1.0 · Windows 10 / 11

開口說話，《魔獸世界：永恆》的聊天框自動打出繁體中文。聽得懂「副本」「天賦」「坦補輸出」，地城和團隊副本名稱也不會打錯。

下載 WowVTX.zip

需要你自己的 OpenAI API 金鑰。每句話約 NT$0.01。

安裝

  1. 在 WowVTX.zip 上按右鍵，選「內容」。勾選最下方的「解除封鎖」，按「確定」。這樣 Windows 就不會擋這個程式。
  2. 解壓縮 WowVTX.zip，會得到一個 WowVTX 資料夾。
  3. 到 platform.openai.com/api-keys 建立 API 金鑰，並在帳單頁面儲值少量額度。
  4. 雙擊 WowVTX.exe，會開啟魔獸VTX 設定視窗。如果出現藍色的「Windows 已保護您的電腦」，按文字裡的「其他資訊」，再按「仍要執行」。
  5. 把金鑰貼到「1. OpenAI API 金鑰」，按「測試金鑰」。下方顯示「金鑰可以用」就對了。
  6. 在「2. 麥克風」選你的麥克風，說話時綠條會動。
  7. 按「儲存並套用」。視窗不要關，縮小就好。
  8. 遊戲的顯示模式設為「視窗（全螢幕）」。

這個程式沒有付費簽章，所以 Windows 會提醒。每次下載新版本都要再做一次第 1 步。

快捷鍵

按鍵功能提示音
F8開啟／關閉語音音調上升＝開，下降＝關
F9切換「按住說話」／「持續聆聽」一聲＝按住說話，兩聲＝持續聆聽
F10切換「手動送出」／「自動送出」一聲低音＝手動，兩聲高音＝自動
右 Ctrl按住說話，放開後轉成文字短促一聲

這些是預設按鍵。想換成自己習慣的鍵：在魔獸VTX 視窗的「3. 快捷鍵」按一下要換的按鈕，再按新的鍵，最後按「儲存並套用」。

怎麼用

  1. 在遊戲中按 F8 開啟語音。
  2. 按住 右 Ctrl，說話，然後放開。
  3. 聊天框會打開並填好文字。檢查一下，按 Enter 送出。

「持續聆聽」模式下，每停頓 0.7 秒就會送出一句。跟 Discord 或身邊的人講話時，記得先按 F8 關掉。

文字會送到聊天框目前的頻道。先打一次 /p、/g 或 /s 選好頻道，再開始說話。

調整

持續聆聽太敏感或聽不到你：看「2. 麥克風」的音量條。先說話，再安靜，把紅線拉到兩者之間：說話時綠條超過紅線，安靜時在紅線左邊。

用錯麥克風：在「2. 麥克風」選另一個，按「儲存並套用」。

換快捷鍵：在「3. 快捷鍵」按一下按鈕，再按想用的鍵。

某個詞一直打錯：按「編輯詞彙表…」，加一行修正，例如 天府=天賦。新的地名、首領或物品名稱直接加一行即可。存檔後按「儲存並套用」。

注意事項

  • 程式用剪貼簿貼上文字，會覆蓋你上一次複製的內容。
  • 如果聊天框已經打開，程式按下的 Enter 會先送出你原本打的字。
  • 每則聊天訊息最多 255 個字。持續聆聽模式下，一句話最長 15 秒。
  • 你的金鑰只存在你自己的電腦，語音只會傳給 OpenAI 轉成文字。
  • 這個工具的運作方式和自己貼上文字一樣，但暴雪沒有正式認可這類工具。是否使用「自動送出」請自行斟酌。
